INKSTORM（墨嵐）

コンパイル方法
  Linux 上でソースを展開し、Makefile のあるディレクトリで実行します。
  GNU Make、GCC、raylib 6.2 のヘッダと静的ライブラリ、OpenGL と X11 の
  開発用ライブラリが必要です。

    make
    make run

  raylib の既定の配置先は $HOME/.local/opt/raylib-6.2 です。
  別の配置先を使う場合は include/raylib.h と lib/libraylib.a を含む
  ディレクトリを指定してください。

    make RAYLIB_DIR=/path/to/raylib-6.2
    ./inkstorm --headless-smoke

  ビルド成果物は make clean で削除できます。

操作方法
  タイトル / ロビー:
    上下 / Enter / 1 〜 4 / クリック  「出陣」「墨庵」「設定」「終了」を選択
    左ドラッグ（余白）                和紙キャンバスに墨を描いて試す
    Esc / 閉じるボタン                アプリケーションを終了

  筆スタイル選択:
    左右 / Enter / 1 〜 3 / クリック  豪筆・朱筆・細筆を選んで出陣
    Esc / 戻るボタン                  ロビーへ戻る

  墨庵（メタショップ）:
    矢印 / Enter / クリック   墨晶で恒久強化 4 種・大遺物解放 6 枠を購入
    Esc / 戻るボタン          ロビーへ戻る

  設定画面（ロビーおよびポーズメニューから開けます）:
    上下                      項目選択（マスター/BGM/SE 音量、ポストシェーダ、
                              画面揺れ、操作ヒント、表示言語、閃光軽減、
                              カーソル倍率、初回ヒントを初期化、設定を既定に戻す）
    左右 / Enter / クリック   値を変更（即時反映・保存）または初期化を実行
    Esc / 戻るボタン          設定をセーブして元の画面へ戻る

  戦闘中:
    左ドラッグ                風筆（風と墨を描き、敵弾を偏向する）
    右クリック / E            渦印（渦を起こし、敵弾・墨・墨玉を集める）
    Space                     風斬り（直線の突風で敵を吹き飛ばし叩きつける。
                              「二段風斬り」Lv3 で 2 チャージ蓄積可能）
    Esc                       ポーズメニューの開閉
    ※第 3 幕には味方に結界を張り追尾符を放つ「狐符」および、3 つの龍玉
      （炎・雷・風）を宿す多部位の一筆龍が登場します。

  ポーズメニュー（ラン中）:
    上下 / Enter / 1 〜 4 / クリック  「再開」「最初から」「設定」「ロビーへ戻る」
    Esc                               再開（確認ダイアログ中はキャンセル）
    ※「最初から」「ロビーへ戻る」は確認ダイアログの後に現在の出陣を
      敗北として精算・保存します（第 1 幕開始直後の幕転換中を除く）。

  報酬画面（強化札 28 種 / 大遺物 15 種 / 候補枯渇時 2 択）:
    1 〜 3 / クリック         強化札または大遺物を選ぶ
    R / クリック              候補を引き直す（リロール）
    4 / クリック              社を修繕する（強化札時）
    1 または 4 / 2 / クリック 候補枯渇時は「社を修繕（超過分は墨晶変換）」
                              または「墨晶を得る」の 2 択から選択

  リザルト画面・エンドレスモード:
    クリック                  「エンドレスへ進む」（本編第 3 幕クリア時のみ。
                              未精算のまま大遺物報酬を受け取って第 4 幕以降へ
                              周回継続し、終了時に一括精算します）
    Enter / Esc / クリック    「ロビーへ戻る」（精算・保存）
    クリック                  「再出陣」（精算・保存して新しく出陣）

  その他:
    F1                        X 線オーバーレイ（流体速度ベクトル・渦度・固体境界枠・
                              属性セル数・描画/流体計測）の切替
    閉じるボタン              終了（ラン中なら敗北として精算・保存して終了）

CLI オプション
  --no-post             和紙ポストシェーダを無効にして直接描画する
  --no-save             セーブファイルを読み書きせずに起動する
  --save-path PATH      セーブファイルの保存先を明示指定する
  --demo                固定シードの自動プレイデモを起動する（F1 切替・Esc 終了）
  --snap DIR            指定ディレクトリへ要所 PNG 6 枚（snap_01.png 〜 snap_06.png）を
                        オフスクリーン描画で自動保存して終了する
                        （単独指定はデモ 6 枚、--showcase --snap DIR で見本帳 6 枚）
  --showcase            全登場物・反応・UI 部品を確認する見本帳シーンを起動する
  --smoke-frames N      隠しウィンドウで N フレーム描画して終了する（N は正の整数）
  --headless-smoke      ウィンドウを開かずに動作確認を行う

セーブ先
  次の優先順で保存先を決定します（--no-save / --headless-smoke / --smoke-frames /
  --showcase / --demo / --snap では読み書きしません）。
    1. --save-path PATH で指定したパス
    2. $XDG_DATA_HOME/inkstorm/save.txt（絶対パスの場合）
    3. $HOME/.local/share/inkstorm/save.txt
    4. 実行ファイルと同じディレクトリの inkstorm_save.txt

フォント・BGM とライセンス
  本文・数値には明朝体（assets/fonts/ui_mincho.ttf）、題字・落款・大反応名には
  毛筆体（assets/fonts/title_brush.ttf）を使用します。
  毛筆体が欠けている場合は明朝体へ、明朝体も読み込めない場合は組み込みフォントによる
  英語（ASCII）表示へ自動的に切り替わります。

  BGM には assets/audio/bgm_*.ogg（ロビー・通常戦・ボス戦・勝利ジングル）を使用します。
  音源が見つからない、または読み込めない場合は、組み込みのプロシージャル和風 BGM へ
  自動的に切り替わります。

  同梱フォント 2 書体および外部 BGM のライセンス・出典は assets/LICENSES.txt と
  assets/fonts/OFL.txt を参照してください。
