> **位置づけ**: 本ドキュメントは INKSTORM（墨嵐）のゲーム仕様・ローグライト拡張設計の Single Source of Truth（[PLAN.md](PLAN.md) Section 6 の詳細版）である。
> 技術設計（Simulation Pipeline / Fluid API / Hybrid ECS / データスキーマ / セーブ）は [architecture.md](architecture.md) で定義する。
> 世界観・見た目の様式・描画規約（パレット、筆描画プリミティブ、NG 集）は [art-direction.md](art-direction.md) で定義する。

> **数値の扱い**: 本書の数値はリファレンス実装 `../../prototypes/inkstorm/` の実装値を基準にした**初期値**であり、`EnemyDef` / `UpgradeDef` などの定義テーブルで調整する。調整で値を変えたら本書も更新する。条件・優先順位・例外などの**規則**は実装と一致させる。

## 1. コアコンセプトとプレイ体験

- **ジャンル**: 2D 水墨流体アクション・ローグライト
- **コア体験**:
  - 和紙キャンバス上の 160×90 非圧縮流体シミュレーションを筆さばきで操り、**敵弾の風偏向・敵の壁/柱叩きつけ・墨/炎/雷の流体連鎖反応**で押し寄せる妖怪の群れから中央の社（Shrine）を護り抜く。
  - 戦闘中の「筆で描く → 流れと墨が生まれる → 属性が連鎖して敵弾や妖怪を巻き込む → 墨玉を回収してさらに描く」という循環と、ウェーブ間・幕ボス撃破後のビルド構築による爆発的な強化感を両立する。
- **勝敗条件**:
  - **敗北（落墨）**: 社の HP が 0 になる。
  - **クリア**: 第 3 幕の最終ボスを撃破する（クリア後はエンドレスモードへ継続可能）。
- **基本ルール**（本書の全仕様に優先する）:
  1. 流体（風・墨・炎・雷）はプレイヤーと敵が共有する。敵が起こす風も、敵弾・墨玉・軽い敵・プレイヤーの墨を運ぶ。
  2. 属性反応と属性ダメージ（炎上・雷撃・爆雷・三元共鳴）は**敵にのみ**作用する。社が被弾するのは、偏向されていない敵弾の命中と敵の接触だけである。
  3. プレイヤーには直接の射撃がない。攻撃手段は「流れで敵弾を偏向して撃ち返す」「敵を叩きつける」「属性反応を起こす」の 3 つである。

## 2. 用語・座標・数値単位

- **画面**: 論理解像度 1280×720。流体格子は 160×90 で、1 セルは 8px。位置は画面 px で表す。
- **流体量**: 墨・炎・雷はセルごとの無次元値で、0〜2.5 にクランプする。流体速度は格子単位（セル/s）で注入し、ゲーム側で判定するときは px/s（×8）へ換算する。
- **時間**: 固定 60Hz。本書の秒数は、実装時に tick（×60）へ変換する。
- **HP・ダメージ**: 整数。プロトタイプの値の **10 倍**（例: 弓妖の HP 2 → 20）にして、% 補正が効く粒度を確保する。

| 用語 | 意味 |
| :--- | :--- |
| 社（やしろ） | 防衛対象。画面中央 (640, 360) に置く |
| 墨ゲージ | 3 つの技が消費する資源（0〜上限） |
| 風筆 / 渦印 / 風斬り | プレイヤーの 3 つの技（§5.2） |
| 偏向 | 敵弾が流れで向きを変えられ、敵を狙う弾に変わること（§8.2） |
| 墨印 / 炎上 / 帯電 / 吹き飛び / 叩きつけ | 状態異常と物理ダメージ（§6） |
| 墨玉 | 撃破時にドロップする回収物。墨を回復する |
| 一筆連殺 | 撃破の連鎖（チェイン） |
| 墨昇華（Ink Surge） | 一筆連殺で発動する強化状態 |
| 強化札 | 通常ウェーブ後に 3 択で得る強化（Lv1〜3） |
| 大遺物（Relic） | 幕ボス撃破後に 3 択で得る、ルールを変える報酬 |
| 墨晶 / 墨庵 | メタ通貨 / ロビーのメタショップ |
| 墨還り | ウェーブ終了時に、残った敵と敵弾が墨に溶けて消える処理 |

## 3. ラン構造とウェーブ

### 3.1 ラン構成
- **幕 × ウェーブ防衛型**: 全 3 幕、各幕「通常 3 ウェーブ ＋ 幕ボス 1 ウェーブ」（計 12 ウェーブ）。
- **目標プレイ時間**: 通常ウェーブ 25〜40 秒、ボスウェーブ 50〜80 秒。報酬選択を含めて 1 ランで約 6〜10 分（序盤からビルドが動き出し、第 3 幕でシナジーが完成するテンポ）。
- **1 ランで得る報酬**: 強化札 9 回、大遺物 2 回（第 1・2 幕のボス後）。第 3 幕のボスを倒すとラン勝利になり、エンドレスへ進む場合に限って 3 回目の大遺物を受け取る。
- **開始**: 筆スタイルを選んで第 1 幕第 1 ウェーブから始める。墨ゲージは満タン、社 HP は最大。

### 3.2 ウェーブの進行規則
- **撃破ノルマ制**: ウェーブの開始時に初期編成が出現し、その後は増援間隔ごとに 1 体ずつ追加される（同時出現上限まで）。ノルマ数を撃破したらクリアになる。
- **数え方**: その幕の通常敵とエリートを数える。ボスが召喚した敵は数えない。
- **クリア時**: 残った敵と敵弾は「墨還り」で 0.6 秒かけて消える（撃破扱いにはせず、スコアと墨玉もない）。場の墨玉は自動で回収する。流体は 1.0 秒そのまま流れ続け、その後に報酬画面へ移る。
- **報酬画面中**: ゲームシミュレーション（流体を含む）を止める。止まった戦闘画面を和紙越しに薄く残して描く。
- **ボスウェーブ**: ボスと護衛で始まり、ボスを倒すとクリアになる（ノルマなし）。増援は同時 4 体まで、2.4 秒間隔。
- **新しい敵の紹介**: 初登場ウェーブの初期編成に必ず 1 体を含め、画面上部に名前と一言説明を 2 秒間表示する。

- 砲台型（弓妖・提灯妖）は、画面端から 76〜165px の外周帯を巡回する。

### 3.5 幕間・クリア・敗北
- **ボス撃破後**: 墨玉 8、社 HP +3 → 1.0 秒の余韻 → 大遺物 3 択 → 幕転換。
- **幕転換**: 幕名の題字（例:「第二幕　鳥居と岩柱」）を 2 秒間表示する。その間に流体（速度と全チャンネル）を 0 に戻し、新しい地形を置く。強化札・大遺物・社 HP・スコアは持ち越す。
- **敗北**: 社 HP が 0 になった時点でシミュレーションを止め、社が砕ける演出（1.5 秒）の後にリザルトへ移る。
- **勝利**: 第 3 幕のボスを倒すと勝利リザルトを表示し、「精算してロビーへ」か「エンドレスへ進む」を選ぶ。

### 3.6 エンドレスモード（第 4 幕以降）
- 勝利リザルトから、構築済みのビルドのまま続けられる（ロビーからは始められない）。
- 進む前に、第 3 幕ボスの報酬（大遺物 3 択 ＋ 社 HP +3）を受け取る。
- 第 4 幕以降は、第 1 → 2 → 3 幕の地形とボスを周回する。周回数を n（第 4〜6 幕が n = 1）として、次の補正をかける。

| 項目 | 補正 |
| :--- | :--- |
| 通常敵の HP | ×(1 + 0.25n) |
| ボスの HP | ×(1 + 0.35n) |
| ノルマ | +2n |
| 増援間隔 | ×0.95ⁿ（下限 0.6 秒） |
| エリート出現率 | +4n %（上限 30%） |
| ボスの攻撃間隔 | ×0.9ⁿ（下限 ×0.7） |

- 報酬は本編と同じ。すべての強化札が Lv3 に達したら、強化札の代わりに「社を修繕 +1」と「墨晶 +10」の 2 択を出す。
- 社 HP が 0 になると終了し、そこまでの成績で精算する。

## 4. ステージ空間と流体連動ギミック

### 4.1 社
- 画面中央の (640, 360) に 1 基を固定で置く。当たり判定の半径は、敵弾に対して 32px、敵の接触に対して 42px。
- データ上は位置と半径を持つ構造体として扱い、固定座標を直書きしない（位置変更や複数拠点への拡張余地を残す）。
- 社から 120px 以内には `solid` を置かない。

### 4.2 障害物（`solid` セル）の規則
- **流体**: `solid` セルは流体の壁になる。流れは壁で反射・回り込み、狭い隙間で加速する（境界条件は [architecture.md](architecture.md) §4.3）。`solid` セルの墨・炎・雷は常に 0 とする。
- **敵弾**: `solid` に当たると消える（偏向済みの弾も同じ）。跳弾雷球だけは反射する。
- **敵**: 歩く敵や吹き飛ばされた敵は、`solid` にぶつかると表面に沿って滑る。吹き飛び中に条件を満たすと叩きつけ（§6.3）になる。
- **経路**: 経路探索は行わない。そのため `solid` は凸形状に限り、`solid` 同士の隙間を 6 セル（48px）以上空けて、行き止まりを作らない。
- **墨玉・火花**: `solid` に当たると止まり、表面に沿って滑る。
- 配置は幕ごとの固定データで持ち、乱数では変えない。

### 4.3 幕ごとの地形とギミック
- **第 1 幕『開けた和紙の社』**: 障害物なし。基本の筆さばき・弾の偏向・紅蓮墨嵐と雷墨連鎖を習得する幕。
- **第 2 幕『鳥居と岩柱』**: 流れの反射・狭路での加速・柱への叩きつけが活きる幕。
  - **鳥居 2 基**: 社の左右（社から ±260px）に置く。各鳥居は 2×2 セルの柱 2 本で、柱の間に 6 セルの隙間を空け、隙間を社の方へ向ける。隙間を抜ける流れは加速し、柱は叩きつけの壁になる。笠木（横木）は描画だけで、`solid` にはしない。
  - **岩柱 4 本**: 社から (±300px, ±170px) の付近に、半径 3 セルの円柱を置く。
- **第 3 幕『嵐の霊峰』**: 地形に加えて、動的なギミックが入る総力戦の幕。
  - **地形**: 岩柱 2 本（第 2 幕の上側 2 本と同じ位置）と霊柱 3 本。
  - **山颪（環境風）**: 12 秒周期で吹く。吹く 1.5 秒前に、風上の画面端で和紙がはためく演出と墨の矢印で予告する。その後 3 秒間、風上の辺から幅 20 セルの帯に、流速を 96px/s へ近づける力を毎ティック加える。風向きは 4 方向から戦闘用 RNG で選ぶ。敵弾・墨玉・軽量の敵・プレイヤーの墨が流される。
  - **霊柱**: 社を中心に半径 230px の正三角形の頂点に置く、半径 2 セルの `solid` 柱。表面に接するセルで炎 > 0.4 か雷 > 0.4 になると「灯る」。灯った霊柱は 6 秒間、0.5 秒ごとに周囲（半径 4 セル）へその属性を 0.5 注入する。灯っている間に同じ属性を浴びると持続が 6 秒に戻り、別の属性を浴びるとその属性に切り替わる。
- 各幕の情景・地色・背景と地形の描き方は [art-direction.md](art-direction.md) §6 に従う。

## 5. 操作体系・墨経済・筆スタイル

### 5.1 入力
操作の直感性と和紙キャンバスの視認性を守るため、戦闘中の技は 3 種に統一する。筆スタイル・強化札・大遺物で、各技の挙動・属性・墨経済を変形させる。

| 入力 | 技 | 墨 / CD | 基本役割 |
| :--- | :--- | :---: | :--- |
| **左ドラッグ** | 風筆（Brush Stroke） | 移動距離に比例 | 筆の軌跡に沿って速度場と墨を注入する。敵弾の偏向と墨塗りの主軸 |
| **右クリック**（代替: `E`） | 渦印（Cyclone Seal） | 26 / 1.4 秒 | カーソル位置に強い回転渦を作り、敵弾・墨・墨玉・軽い敵を 1 点へ集める |
| **Space** | 風斬り（Gale Burst） | 16 / 1.0 秒 | カーソル位置から直近の筆運びの向きへ直線の突風を放ち、敵を壁・障害物へ叩きつける |

| システム入力 | 内容 |
| :--- | :--- |
| `Esc` | ポーズメニュー（再開 / 最初から / 設定 / ロビーへ戻る） |
| `F1` | X 線表示（流体の速度ベクトル・渦度・流体の計算時間・属性セル数） |
| 報酬画面の `1`〜`3` / クリック | 札（遺物）を選ぶ |
| 報酬画面の `R` / `4` | リロール / 社を修繕 |

- 戦闘中のリセットキーは置かない。やり直しはポーズメニューの「最初から」で行う（敗北として精算する）。

### 5.2 技の詳細
**風筆**
- 左ボタンを押している間、毎ティック、前回のカーソル位置から現在位置までの線分に沿って注入する（5px ごとに 1 点、最大 18 点）。
- 注入する速度はマウス移動量 ×0.58（成分ごとに ±46 セル/s で制限）、半径は 3.7 セル。墨の量は移動距離に応じて 0.26〜0.65。
- 消費は毎ティック「0.16 ＋ 移動距離(px) × 0.028」。筆を止めたまま押し続けても毎秒約 9.6 減るので、押しっぱなしでは得をしない。墨が 0.5 以下のときは何も注入しない。

**渦印**
- 発動時に、カーソル位置へ半径 15.5 セル・接線速度 54 セル/s の回転渦（画面上で時計回り）と、墨 0.92 を注入する。
- 持続は 0.72 秒。最初の 55% の間は、半径 13 セル・接線速度 18 セル/s の渦を毎ティック追加する。
- 半径 220px 以内の墨玉を、渦の中心へ 320px/s の速度で引き寄せる。
- 直接のダメージはない。

**風斬り**
- **始点**: カーソル位置。
- **向き**: 直近の筆運びの向き。マウスが 2px を超えて動いたティックごとに「前の向き ×0.65 ＋ 新しい向き ×0.35」で平滑化する。まだ向きがない場合は「社 → カーソル」の向きを使う。
- **流体**: 向きに沿って 20px 間隔で 12 点（計 240px）、半径 4.6 セル、速度 52 セル/s で注入し、各点に墨 0.28 を加える。
- **直接効果**: 始点から 245px 以内で、向きとの cos が 0.35 を超える敵に 560px/s の衝撃を与え（質量で補正、§6.2）、吹き飛びを 1.15 秒付ける。230px 以内で cos が 0.25 を超える敵弾は偏向済みにし、向きの方へ 480px/s で飛ばす。
- 直接のダメージはない（叩きつけで倒す）。

### 5.3 墨経済（Ink Economy）

| 項目 | 初期値 |
| :--- | :--- |
| 墨ゲージ上限 | 100。各ウェーブの開始時に満タンへ戻す |
| かすれ筆（Dry Brush） | 墨が 20 未満のとき、風筆の力 ×0.46・墨 ×0.34・半径 2.8 セル。筆致が 1 点おきに途切れる（ビルドや遺物で逆利用できる） |
| 硯（自然回復） | 筆を離している間は毎秒 15、離して 0.32 秒経つと毎秒 26。渦印・風斬りを使っても止まらない |
| 墨玉（Ink Orb） | 墨 +16・スコア +25。流体の流れに乗って漂う。筆カーソルから 130px 以内では加速度 (130 − 距離) × 5.2 px/s² で引き寄せられ、46px 以内で回収される。社から 44px 以内に流れ着いても回収される。寿命は 11.5 秒（最後の 2 秒は点滅） |
| 墨玉のドロップ数 | 敵ごとに決める（§8.1）。エリートは 5、ボスは 8 |
| 技の発動条件 | 墨がコスト以上で、CD が 0。満たさないときは発動せず、カーソル下の準備ピップが揺れて知らせる |

### 5.4 一筆連殺と墨昇華
- **一筆連殺（チェイン）**: 撃破から 2.65 秒以内に次の敵を倒すとチェイン +1 になり、猶予がリセットされる。社が被弾するとチェインは 0 に戻る。
- **連殺ボーナス**: チェイン ×2 以上で倒すたびに、墨 +8 × min(チェイン, 4)。
- **墨昇華（Ink Surge）**: チェイン ×2 以上で倒すたびに発動し、残り時間を 3.6 秒に戻す。効果は、全技の墨消費 ×0.5、風筆の力 ×1.18・半径 4.2 セル。筆に金色のオーラが付く。
- **連殺の雷**: チェインが 3 の倍数に達した撃破地点に、半径 6.2 セルで墨 0.55・雷 1.15 を注入する（どのビルドでも使える雷の発生源）。
- **スコア**: 撃破の基礎点（§8.1）× max(チェイン, 1)。墨玉の回収は +25。

### 5.5 社
- 最大 HP 8、被弾後の無敵時間 0.95 秒。被弾するとチェインが 0 に戻り、社の周囲に小さな渦が起きてプレイヤーの墨が乱れる。
- 回復手段: ボス撃破で +3、報酬画面の「社を修繕」で +1、一部の強化札と大遺物。

### 5.6 初期「筆スタイル」3 種（初回から解放）
ラン開始時に 3 種の筆から 1 つを選ぶ。初回起動時からすべて解放しておき、最初から違う手触りを試せるようにする。

| 筆スタイル | 特徴 | 修正値 | 推奨軸 |
| :--- | :--- | :--- | :--- |
| **豪筆（Heavy Brush）** | 太く強い筆致。偏向と壁/柱叩きつけが得意なバランス型 | 筆の半径 ×1.25、力 ×1.2、風筆の消費 ×1.15、風斬りの衝撃 ×1.25 | 烈風・墨道 |
| **朱筆（Ember Brush）** | 筆跡と風斬りに火種を混ぜ、自分で着火できる高火力型 | 筆跡 120px ごとに火種（炎 0.5・半径 2.5 セル）、風斬りの各注入点に炎 0.35、かすれ筆の間は火種なし、風筆の消費 ×1.2 | 紅蓮・雷霆（爆雷） |

- 見た目も筆ごとに変える（豪筆＝太い濃墨、朱筆＝朱の混じる筆致と火の粉、細筆＝細い淡墨と蒼い火花）。カーソルの形も筆ごとに変える。

### 6.1 状態異常

| :--- | :--- | :--- | :--- |
| **墨印（Ink-Marked）** | 敵の位置の墨 > 0.28 | 3.0 秒（条件を満たす間は更新） | 受けるダメージ ×2.0（ボスは ×1.5）。移動・攻撃の速度 ×0.66 |
| **炎上（Burning）** | 敵の位置の炎 > 0.42 | 条件を満たす間 | 0.36 秒ごとに 10 ダメージ（ボスは 0.55 秒ごと）。条件を外れると、蓄積した時間が半分の速さで減る |

### 6.3 叩きつけ（Slam）
- **壁・障害物**: 吹き飛び中の敵が 215px/s を超える速さで画面端の壁か `solid` に当たると成立する。
- **敵同士**: 吹き飛び中の敵が 205px/s を超える速さで別の敵（判定半径 34px、ボスは 54px）に当たると、当たられた側に 40 ダメージを与え、飛ばされた側も叩きつけと同じダメージを受ける。
- 叩きつけで倒したときは「叩きつけ！」を表示し、0.05 秒のヒットストップを入れる。
- 叩きつけのダメージにも墨印の倍率がかかる（即撃破は無条件）。

### 6.4 ダメージ一覧（初期値）

| 発生源 | ダメージ | 分類 |
| :--- | :--- | :--- |
| 偏向した矢・鎌風・追尾符 | 20 | 物理 |
| 偏向した火球 | 30（命中点に炎 0.7） | 物理 |
| 偏向した雷球・跳弾雷球 | 20 ＋ 雷撃弾の効果 | 物理 |
| 炎上弾 | 40、貫通 2 | 炎 |
| 雷撃弾の追加雷撃 | 10 × 1 体 | 雷 |
| 炎上 | 10 / 0.36 秒 | 炎 |
| 雷墨連鎖 | 10（ホップごとに ×0.7） | 雷 |
| 爆雷 | 30 | 炎・雷 |
| 三元共鳴 | 80 ＋ 雷撃 30 × 4 体 | 炎・雷 |

## 7. 属性体系と流体反応（Fluid Alchemy）

流体チャンネルは、和紙上で視認性のコントラストが最も高い **3 属性（黒：墨 `ink`／朱：炎 `fire`／蒼：雷 `storm`）** を深化させる。
（※Fluid Engine 自体は汎用多チャンネル設計とし、将来的なチャンネル追加の余地は維持する。）

### 7.1 チャンネル特性

| 属性 | 色 | 減衰 / tick（半減期） | 主な発生源 | 役割 |
| :--- | :--- | :--- | :--- | :--- |
| 墨 `ink` | 黒 | 0.985（約 0.8 秒） | 風筆・渦印・風斬り・撃破時の飛沫 | 燃料と導体。墨印を付ける |
| 炎 `fire` | 朱 | 0.935（約 0.17 秒） | 提灯妖・炎、火球、朱筆、紅蓮の札 | 墨の上で燃え広がる |
| 雷 `storm` | 蒼 | 0.905（約 0.12 秒） | 提灯妖・雷、雷球、連殺の雷、細筆、雷霆の札 | 墨を伝って走る |

- 色だけに頼らない。炎は揺らぐ火の粉、雷は折れ線の稲妻という形でも区別できるように描く。

### 7.2 反応の処理順
毎ティック、流体を更新した後に次の順で判定する（`game/elements` の責務）。

1. セル単位の反応（紅蓮墨嵐の燃焼、墨の上での雷の成長）
2. 三元共鳴の判定（成立したブロックは、そのティックの爆雷判定から外す）
3. 爆雷の判定
4. 敵への状態付与とダメージ（墨印・炎上・帯電・雷墨連鎖）
5. 敵弾の属性変化（炎上弾・雷撃弾・加速）

- 爆雷と三元共鳴の放射インパルスは、次のティックの流体更新の前に注入し、必ず流体側の速度クランプを通す。

### 7.3 反応一覧

| 組み合わせ | 反応名 | 効果の要約 |
| :--- | :--- | :--- |
| **墨 × 炎** | **紅蓮墨嵐（Blazing Inkstorm）** | 墨の領域が着火・延焼して範囲に継続ダメージ。通過した弾が貫通する炎上弾に昇格する |
| **墨 × 雷** | **雷墨連鎖（Tempest Lightning）** | 墨の領域を導体として、敵の間を電撃が連鎖する |
| **炎 × 雷** | **爆雷（Thunderburst）** | 強い放射状の流体インパルス（爆風）と範囲ダメージ。重量級も含めて周囲の敵を吹き飛ばす |
| **墨 × 炎 × 雷** | **三元共鳴（Cataclysm）** | 3 属性が重なった領域で、大爆風・広域連鎖・高ダメージを起こす最上位の反応 |

**紅蓮墨嵐（墨 × 炎）**
- **セル条件**: 炎 > 0.14 かつ 墨 > 0.20。
- **燃焼**: 燃焼量 = min(墨, 炎) × 0.030 × (1 + min(2.4, |渦度| × 0.28))。炎に燃焼量 × 1.15 を足し、墨から燃焼量 × 0.14 を引く。渦の中ほど速く燃え広がり、墨は少しずつ減る。
- **表示**: 炎 > 0.34 のセルを燃焼セルとし、燃焼セルが 24 以上になった瞬間に「紅蓮墨嵐！」を表示する（次の表示まで 3.2 秒空ける）。
- **効果**: 敵の炎上（§6.1）。偏向済みの弾、または墨 > 0.16 の上にある弾が炎 > 0.36 のセルを通ると、炎上弾（貫通 2、速度 ×1.25、最高速 640px/s、追尾力 ×1.2）に昇格する。

**雷墨連鎖（墨 × 雷）**
- **セル条件**: 雷 > 0.14 かつ 墨 > 0.24 のセルで、雷に min(墨, 雷) × 0.015 を足す（墨の上で雷が育つ）。
- **発動**: 雷 > 0.24 のセルが 10 以上あり、雷撃の CD（0.54 秒）が 0 のとき。各敵について、周囲 195px 以内で最も強い雷セル（> 0.28）を探す。その敵が墨印か帯電の状態にあるか、そのセルから 150px 以内にいれば、セルから敵へ雷撃（10）を落とす。1 回の発動で最初に落とす雷撃は 1 本。
- **連鎖**: 雷撃を受けた敵から、160px 以内にいる墨印または帯電の敵へ跳ぶ。基本は 2 ホップで、ホップごとにダメージ ×0.7。同じ敵は 1 回の連鎖で 1 度しか撃たない。
- **雷撃弾**: 偏向済みの弾が雷 > 0.25 のセルを通ると雷撃弾になる。命中すると、160px 以内の別の敵 1 体へ雷撃（10）が走る。
- **偏向前の敵弾**: 雷 > 0.25 のセルを通ると、1 回だけ速度 ×1.3 になる（雷は弾を速くする）。

**爆雷（炎 × 雷）**
- **セル条件**: 炎 > 0.30 かつ 雷 > 0.30 のセルを爆雷セルとする。
- **判定**: 格子を 8×8 セルのブロック（横 20 × 縦 12）に分ける。爆雷セルが 6 以上あり、ブロックの CD が 0 のブロックで発動する。中心は爆雷セルの重心。
- **効果**: 中心から半径 9 セル（72px）に外向きの放射インパルス（中心付近で最大 60 セル/s）を加える。半径 96px 以内の敵に 30 ダメージと 1.0 秒の吹き飛びを与える（重量級も吹き飛ぶ）。半径 9 セル以内の炎を ×0.3、雷を ×0.2 に減らす。
- **制限**: ブロックの CD 0.8 秒、1 ティックに最大 3 回。演出はヒットストップ 0.03 秒と小さな画面揺れ。

**三元共鳴（墨 × 炎 × 雷）**
- **セル条件**: 墨・炎・雷がすべて > 0.30 のセルを共鳴セルとする。
- **判定**: 爆雷と同じブロック単位で、共鳴セルが 8 以上あれば発動する。全体の CD は 2.0 秒（同時に 1 か所だけ）。
- **効果**: 半径 12 セルに爆雷の 1.5 倍の放射インパルスを加える。半径 140px 以内の敵に 80 ダメージと吹き飛びを与えて墨印を付ける。さらに、中心から 260px 以内の敵 4 体へ雷撃（30）を飛ばす。半径以内の墨を ×0.5、炎と雷を ×0.2 に減らす。
- **演出**: ヒットストップ 0.06 秒、大きな画面揺れ、「三元共鳴！」の大きな題字。

### 7.4 能動属性注入
- プロトタイプでは、炎と雷の発生源を主に敵（提灯妖・火球・雷球・大天狗）に頼っていた。本開発では、筆スタイル（朱筆・細筆）と強化札・大遺物によって、プレイヤーからも炎と雷を場へ注入できるようにする。これにより、敵の編成に左右されずに、狙った属性ビルドを回せる。

| 属性 | 基本で使える源 | 筆スタイル | 強化札・大遺物 |
| :--- | :--- | :--- | :--- |
| 墨 | 風筆・渦印・風斬り・撃破時の飛沫 | 全筆 | 墨道の札、墨染めの社 |
| 炎 | 敵の火球・提灯妖・炎（渦印で奪う） | 朱筆の火種 | 紅蓮の札、朱の硯 |
| 雷 | 連殺の雷（チェイン ×3 ごと）、敵の雷球 | 細筆の帯電渦印 | 雷霆の札、雷神の太鼓 |

- 敵の属性（火球・雷球・ボスの技）を渦印で奪って利用するのは、どのビルドでも有効な基本戦術とする。

### 8.2 敵弾

| 弾 | 速度 | 社ダメ | 流体の影響 | 偏向後のダメージ | 備考 |
| :--- | :---: | :---: | :---: | :--- | :--- |
| 矢 | 250px/s | 1 | ×1.0 | 20 | 基本の弾 |
| 火球 | 195px/s | 1 | ×1.0 | 30 | 軌跡に炎を残す（墨の上で着火する） |
| 雷球 | 210px/s | 1 | ×1.0 | 20 ＋ 雷撃弾 | 軌跡に雷を残す |
| 鎌風 | 300px/s | 1 | ×1.5 | 20 | 流れに乗りやすく、逸らしやすい |
| 追尾符 | 140px/s | 1 | ×0.6 | 20 | 社へ毎秒 90° まで旋回して追う。炎 > 0.3 で燃え尽きる |
| 跳弾雷球 | 230px/s | 1 | ×1.0 | 20 ＋ 雷撃弾 | 壁と `solid` で最大 2 回反射する（鵺） |

- **流体の影響**: 敵弾は毎ティック、流速 × 5.0 × 影響係数（/s）の加速を受ける。
- **偏向の判定**: 弾の位置の流速が 48px/s を超え、かつ弾の向きと社の方向の cos が 0.90 未満のとき、または流速に関係なく cos が 0.28 未満になったとき、偏向済みになる。偏向済みの弾は敵を狙う弾として扱い、社には当たらない。
- **偏向後の追尾**: 620px 以内で最も近い敵（ボスは距離を ×0.65 として優先する）へ、700px/s² で舵を切る（炎上弾は 840px/s²）。
- **速度の範囲**: 180px/s から最高速まで。最高速は、偏向前 365px/s、偏向後 550px/s、炎上弾 640px/s。
- **消滅**: 寿命 7.5 秒。画面の外へ 45px 出ると消える。`solid` に当たると消える（跳弾雷球を除く）。

### 8.3 エリート変異
- **出現**: 第 2 幕の通常ウェーブでは、増援 1 体ごとに 8%（同時 1 体まで、1 ウェーブ 2 体まで）。第 3 幕では 12%（同時 2 体まで、1 ウェーブ 3 体まで）。通常敵が対象（狐符を除く）。
- **共通**: HP ×2.5、体の大きさ ×1.2、変異の色のオーラ。撃破時に墨玉 5、スコア ×3。
- **変異の数**: 第 2 幕は 1 つ、第 3 幕以降は最大 2 つ（重複なし）。同じウェーブで同じ変異が続けて出ないようにする。

| 変異 | 縁の色 | 効果 |
| :--- | :--- | :--- |
| 剛体 | 金 | 質量を 1 段重くする。叩きつけのダメージ −50%。砲台型には付かない |
| 撥墨 | 白 | 墨印にならない。周囲 48px の墨を毎秒 20% 散らす |
| 不燃 | 朱 | 炎分類のダメージ −70% |
| 避雷 | 蒼 | 雷分類のダメージ −70%。雷墨連鎖の中継点にならない |

- 耐性を無効化ではなく軽減にするのは、どのビルドでも倒し切れるようにするためである。

### 8.4 幕ボスの共通規則
- **登場**: 日本語名と異名の題字（2 秒）と、画面上部のボス HP バーを出す。
- **耐性**: 墨印の倍率は ×1.5、雷分類のダメージは −50%、炎上の間隔は 0.55 秒。吹き飛びと即撃破はなく、叩きつけが効くかどうかはボスごとに決める。
- **予兆**: ボスの攻撃には、必ず 0.6 秒以上の予兆（発光・構え・風上の墨の矢印）を出す。
- **フェーズ移行**: 1.5 秒の無敵演出（墨が弾ける）を入れてから、行動パターンを切り替える。
- **護衛**: 増援は同時 4 体まで（ボスが召喚した敵を含む）、2.4 秒間隔。
- **撃破**: 墨玉 8、社 HP +3、スコア 1500 × チェイン、大遺物 3 択（第 3 幕は勝利リザルトへ）。

### 8.5 第 1 幕ボス：大天狗（O-Tengu）「紅風の大天狗」
- HP 400。飛行しているので叩きつけは効かない。画面の上半分を 8 の字に巡回する。
- **パターン**（A → B → C の順に繰り返す）:
  - **A 紅風薙ぎ**: 0.85 秒間、社へ向けて紅の敵風（薄い炎を含む）を注入し、双火球を撃つ。次の攻撃まで 1.95 秒。
  - **B 扇矢**: 扇状に矢を 4 本放ち、0.4 秒の短い突風を吹かせる。次の攻撃まで 1.65 秒。
  - **C 大紅風**: 1.15 秒間の強い敵風でプレイヤーの墨の渦を押し流し、雷球 1 発と矢 2 本を撃つ。次の攻撃まで 2.05 秒。
- **第 2 フェーズ**（HP 50% 以下）: 攻撃間隔 ×0.8。パターン D「羽団扇旋風」を加える。0.8 秒の予兆の後、社の周囲に逆回転の大渦（半径 14 セル・1.2 秒）を起こし、プレイヤーの墨を散らす。
- **攻略**: 敵風は敵弾も社へ運ぶので、風筆で押し返して「風と風」を競う。双火球を渦印で奪って墨に着火し、墨印を付けた本体へ炎上弾を当てる。

### 8.6 第 2 幕ボス：鵺（Nue）「雷雲の鵺」
- HP 700。第 2 幕の鳥居と岩柱の間を移動する、スピード型のボス。
- **移動**: 0.5 秒の予兆（進路に雷光の線）の後、600px/s で次の柱の陰までダッシュし、そこで 1.5 秒止まって攻撃する。
- **パターン**:
  - **A 雷走り**: ダッシュの経路に雷帯を残す（2 秒間、経路上に雷 0.6 を注入し続ける）。
  - **B 跳弾雷球**: 止まっている間に、跳弾雷球を 3 連射する。
  - **C 群れ呼び**: 鎌鼬を 2 体呼ぶ（12 秒に 1 回まで）。
- **第 2 フェーズ**（HP 50% 以下）: 雷帯を 2 本同時に残す。ダッシュの後に「夜鳴き」を使う。0.6 秒の予兆の後、半径 200px の外向きの衝撃波（流体インパルス）でプレイヤーの渦と墨を吹き散らす。
- **叩きつけ**: 止まっている間だけ有効。風斬りや爆雷で柱か壁へ叩きつけると、60 ダメージと 1.0 秒のスタン。
- **攻略**: 雷帯がプレイヤーの墨に触れると、鵺自身にも雷墨連鎖が走る。偏向前の敵弾は雷帯を通ると加速するので、雷帯を墨でつないで利用するか、流れで弾を雷帯から遠ざける。

### 8.7 第 3 幕ボス：一筆龍（Ippitsu-Ryū）「霊峰の龍脈」

- **移動**: 頭は画面の上半分（y 96〜510px）を S 字に泳ぐ。胴は社から 200px 以内に入らない（第 2 フェーズの「龍巻き」を除く）。胴は動いた向きに弱い風を流体へ注入し、プレイヤーの墨をかき混ぜる。
- **当たり判定**: 標的になるのは、龍玉（半径 30px）と、第 2 フェーズからの龍睛（頭・半径 46px）だけ。胴には当たり判定がなく、偏向弾はすり抜ける。
- **第 1 フェーズ「三つの龍玉」**: 龍玉ごとに HP 300 を持つ（龍の本体は無敵）。龍玉は 2.2 秒ごとに 1 つずつ交代で攻撃し、攻撃の 0.6 秒前にその属性の色で光る。

  - **雷玉（胴）**: 雷球 3 発を撃ち、社の周囲 3 か所に落雷を予告する（0.8 秒）。落雷点から 40px 以内に墨 > 0.3 があれば、避雷して社は無傷になり、その点から雷墨連鎖が走る。墨がなく、落雷点が社の当たり判定に重なっていれば社に 1 ダメージ。
  - **風玉（尾）**: 尾で大きく払って社へ向けた大逆風（1.5 秒）を吹かせ、鎌風を 3 発撃つ。
  - 壊した龍玉は再生しない。龍玉が 1 つ減るごとに、残った龍玉の攻撃間隔は ×0.85 になる。
- **第 2 フェーズ「点睛」**: 3 つとも壊すと、墨嵐が龍の目を描き入れ（1.5 秒の点睛の演出）、龍が目覚める。頭の龍睛（HP 900）が弱点になり、頭の泳ぐ速さは ×1.3、山颪の周期は 6 秒に縮まる。

- **第 3 フェーズ「昇龍」**（龍睛の HP 40% 以下）: 攻撃間隔 ×0.8。三元共鳴が龍睛に与えるダメージ ×2。構築した 4 軸ビルドと三元共鳴をぶつけて決着するクライマックス。

## 9. ローグライト報酬ループとビルド

### 9.1 ラン中の報酬ループ（2 層報酬・ラン中ショップなし）
戦闘テンポを最優先し、ラン中はショップ画面を挟まない。「戦闘 → 3 択選択 → 即次ウェーブ」の循環に統一する。

1. **通常ウェーブのクリア後**: **強化札 3 択**（リロールあり）。札は重ねて取ると Lv1〜3 に上がり、効果が強化または派生する。札を取らずに「社を修繕（HP +1）」を選んでもよい。
2. **幕ボスの撃破後**: ラン全体のルールを変える **大遺物 3 択** ＋ **社 HP +3**（第 3 幕のボスはエンドレスへ進む場合のみ）。

### 9.2 提示の規則
- 3 枚は互いに異なる札とし、少なくとも 2 つの軸から選ぶ（共通の札は独立した 1 軸として数える）。
- Lv3 に達した札は出さない。持っている札は、次の Lv の札として出る。
- 各枠で、40% の確率で持っている札（Lv1〜2）から、残りの 60% で全体から抽選する。筆スタイルの推奨軸の札は、重みを ×1.5 にする。
- 最初の報酬（第 1 幕第 1 ウェーブの後）には、推奨軸の札を必ず 1 枚含める。
- **リロール**: 幕ごとに 1 回（墨庵で 1 段ごとに +1、最大 3 回）。その幕の報酬画面（強化札・大遺物）で共有し、3 枚すべてを引き直す。使わなかった回数は次の幕へ持ち越さない。
- **大遺物**: 解放済みで、まだ持っていない遺物から 3 つを出す。
- 提示はランの RNG で決める。同じシードと同じ入力列（報酬の選択・リロールを含む）なら、同じ提示になる（§10.3）。

### 9.3 ビルド軸と目標ボリューム
数値が少し上がるだけの水増しを避け、流体の挙動・技の性質・属性の連鎖を変える効果を中心に設計する。

- **4 つの主要ビルド軸**:
  1. **紅蓮（炎嵐）軸**: 筆と風斬りへの炎の注入、延焼範囲・継続火力の強化、炎上弾の強化
  2. **雷霆（連鎖・爆雷）軸**: 渦と墨への帯電、電撃の連鎖数と射程の拡大、`炎×雷` の爆雷の誘発
  3. **烈風（物理・叩きつけ）軸**: 流速と渦の吸引力の強化、叩きつけの衝撃波、偏向弾の追尾強化
  4. **墨道（墨経済・墨昇華）軸**: 墨玉の増量と広域吸引、墨昇華の延長と発動緩和、かすれ筆の逆利用
- **目標ボリューム**: 通常の強化札 **24〜30 種**（Lv1〜3）、大遺物 **12〜15 種**（初期プール ＋ 墨庵での解放枠）。初期カタログは強化札 28 種・大遺物 15 種とする（§9.4・§9.5）。

| 解放 | 百鬼夜行の巻物（Night Parade Scroll） | 獲得する墨晶 ×1.5、墨玉 +1 | 増援間隔 ×0.75、同時上限 +2 |

## 10. ロビー・メタショップ（墨庵）

ラン終了後（クリア・敗北を問わず）、成績に応じたメタ通貨（**墨晶**）を獲得し、ロビー画面の **墨庵（メタショップ）** で恒久強化と解放を行う。

- **初期解放**: 筆スタイル 3 種（豪筆 / 朱筆 / 細筆）と、初期の大遺物 9 種。
- **バランス原則**: メタ強化のない初期状態でも、腕前とラン中のビルド次第で第 3 幕をクリアできる難易度にする。恒久強化は小幅にとどめる。

### 10.1 墨晶の獲得
墨晶はランの最後に 1 回だけ精算する（エンドレスへ進んだ場合は、エンドレスが終わった時点）。ポーズからの「ロビーへ戻る」と「最初から」も、敗北として精算する。

| 項目 | 墨晶 |
| :--- | :--- |
| 幕のクリア | 第 1 幕 30・第 2 幕 40・第 3 幕 50 |
| 撃破 | 5 体ごとに 1 |
| 最大の一筆連殺 | チェイン数 × 2（上限 30） |
| 反応 | 爆雷 1 回につき 1・三元共鳴 1 回につき 3（合計の上限 20） |
| エンドレス | 1 幕のクリアごとに 40 |

- 目安: 第 2 幕で敗北したランで 60〜80、初めてのクリアで 180〜230。
- 精算の内訳はリザルト画面に表示する。

### 10.2 商品

| 商品 | 段階 | 価格 |
| :--- | :--- | :--- |
| 社の加護（社の最大 HP） | +1 / +2 / +3 | 80 / 140 / 200 |
| 大きな硯（墨ゲージ上限） | +10 / +20 / +30 | 60 / 100 / 140 |
| 早墨（硯の回復） | +10% / +20% / +30% | 60 / 100 / 140 |
| 再考の札（幕ごとのリロール回数） | 2 回 / 3 回 | 100 / 200 |
| 大遺物の解放 | 6 種（解放枠） | 各 100 |

- すべて買うと合計 1,920 墨晶で、12〜18 ランが目安。
- 段階の数は `MetaState` の定義（[architecture.md](architecture.md) §8.1）と一致させる。

### 10.3 再現性とテストの分離
- メタ進行の状態は `RunConfig` としてシミュレーションの初期化時に明示的に注入する。決定性の回帰テストとデモモードでは、固定のプリセットを使って再現性を保証する。
- `RunConfig` に含めるもの: シード、筆スタイル、恒久強化の段階、解放済みの大遺物、エンドレスの周回補正。
- 戦闘と報酬の乱数はランの RNG だけを使う。火花などの見た目だけの演出は描画側の専用 RNG（`vfx_rng`）で作り、戦闘と報酬の結果には影響させない（architecture.md §1.2）。
- 報酬の選択・リロール・修繕は `GameCommand` として入力列に含める。同じシードと同じ入力列でランを再現できるようにする（architecture.md §7.2）。
- リザルト画面にシードを表示する。

## 11. 画面遷移・UI/HUD・アセット方針

### 11.1 シーン遷移
```text
タイトル / ロビー ─┬─▶ 墨庵（メタショップ） ─▶ ロビー
                   ├─▶ 設定 ─▶ ロビー
                   └─▶ 筆スタイル選択 ─▶ 戦闘（第1〜3幕）
                                          ├─▶ 報酬選択（強化札 / 大遺物） ─▶ 次ウェーブ / 幕転換
                                          ├─▶ ポーズ（再開 / 最初から / 設定 / ロビーへ）
                                          └─▶ リザルト（勝利 / 敗北）
                                                 ├─▶ エンドレス継続（勝利時：大遺物3択の後に第4幕へ）
                                                 └─▶ 墨晶精算 ─▶ ロビー
```

### 11.2 各画面の内容
- **タイトル / ロビー**: 「出陣」「墨庵」「設定」「終了」。所持している墨晶、最高到達、最高スコアを表示する。背景では流体がゆっくり動き、マウスで墨を描いて遊べる。
- **筆スタイル選択**: 3 本の筆のカード（特徴・修正値・推奨軸）と、自動で描く試し書きを見せる。選ぶとランが始まる。
- **報酬選択**: 3 枚の札（名前、軸の色のアイコン、現在の Lv → 次の Lv の効果）、リロールの残り回数、「社を修繕」。
- **幕転換**: 幕名の題字を 2 秒間表示する。
- **ポーズ**: 再開 / 最初から / 設定 / ロビーへ戻る。「最初から」と「ロビーへ戻る」は確認ダイアログを出し、敗北として精算する。現在の強化札と大遺物の一覧も表示する。
- **リザルト**: 到達した幕とウェーブ、スコア、撃破数、最大の一筆連殺、反応の回数（紅蓮墨嵐・雷墨連鎖・爆雷・三元共鳴）、取得した札と遺物、シード、墨晶の内訳。
- **設定**: マスター音量・BGM・SE（0〜100%）、ポストシェーダの ON/OFF、画面揺れ（100% / 50% / 0%）、操作ヒントの ON/OFF。メタ進行と同じセーブデータに保存する。

### 11.3 初回の操作ヒント
- 操作ヒントが ON のとき、第 1 幕で状況に応じた短い指示を出す。各ヒントは 1 回だけ出し、表示済みであることをセーブに記録する。
  1. 開始直後:「左ドラッグで風を描き、矢を逸らせ」
  2. 初めて火球が出たとき:「右クリックの渦印で、火球を墨に巻き込め」
  3. 初めて唐傘妖が出たとき:「Space の風斬りで壁へ叩きつけろ」
  4. 初めて墨が 20 を切ったとき:「筆を離すと、硯で墨が戻る」
- 各反応が初めて起きたときは、反応名と一言の説明を出す。
- ヒントを表示している間もゲームは止めない。

### 11.4 UI 言語とフォント
- **日本語メイン UI**: タイトル、筆スタイル、強化札・大遺物のカード、ボス登場の題字、墨庵、HUD、コールアウト（「紅蓮墨嵐！」「雷墨連鎖」「爆雷！」「三元共鳴！」「叩きつけ！」「一筆連殺 ×3」「墨昇華」など）を日本語で統一する。
- **文字列表**: 表示するすべての文字列を、ID・日本語・英語の組として 1 つの文字列表で管理する。
- **フォント同梱とフォールバック**:
  - OFL などのフリーの和風フォント（明朝系か毛筆系の TTF）を `assets/fonts/` に同梱する。文字列表の日本語から使う文字のコードポイントを集め、`LoadFontEx` に渡す。
  - フォントの読み込みに失敗してもクラッシュさせず、組み込みのデフォルトフォントと、文字列表の英語（ASCII）へ安全に切り替える。
- 書体の使い分けと最小の文字サイズ（毛筆体は 40px 以上の題字・落款だけ、本文と数値は明朝体 18px 以上）は [art-direction.md](art-direction.md) §9.6・§12 に従う。

### 11.5 HUD 原則
- 和紙の余白と流体の視認性を最優先する。
- **主表示（カーソルの周囲）**: 墨リング（残量。20 の位置にかすれの目盛りを付け、墨昇華の間は金色にする）と、その下に渦印・風斬りの準備ピップ 2 つを置く。プレイ中に視線を外さずに読めるようにする。
- **画面端（補助）**:
  - 左上: 社 HP（灯火の印）と墨ゲージの数値
  - 上中央: 幕とウェーブ（例: 第二幕 2/3）とノルマ（撃破 7/12）。ボス戦では、代わりにボス名と HP バーを出す
  - 右上: スコアと一筆連殺（猶予のゲージ付き）
  - 右下: 取得した大遺物の小さなアイコン
- 上端の HUD 帯には半透明の和紙を敷き、濃い墨の上でも読めるようにする。
- 予兆（ボスの技、山颪、落雷点）は朱の破線や印で示す。
- HUD の線・色・文字の見た目は [art-direction.md](art-direction.md) §12.1 に従う。

### 11.6 ビジュアル・音響アセット方針（ハイブリッド）
- **ビジュアル**:
  - 様式・パレット・筆描画プリミティブ・描画規約・NG 集・セルフチェック・描画性能予算は [art-direction.md](art-direction.md) を正とする。
  - 和紙ポストシェーダ、160×90 の流体の可視化、プロシージャルな水墨のベクター描画（敵・社・障害物・筆致）を主軸とする。
  - 和紙のテクスチャや落款の印章など、世界観の質感を高めるアクセントにだけ外部画像（`assets/textures/`）を任意で使う。欠けている場合はプロシージャルなノイズへ切り替える。
- **SE**:
  - `ink_audio` のプロシージャルな和楽器・流体シンセ（和太鼓・琴・風音・着火・雷撃・筆擦れ・叩きつけ）をイベント駆動で拡張し、任意の箇所だけ外部 WAV に差し替えられるようにする。
  - SE を鳴らすイベント: 風筆（筆擦れ。筆の速さで音量を変える）、渦印、風斬り、偏向、撃破、一筆連殺（段階が上がるほど音程も上げる）、墨昇華、墨玉の回収、紅蓮墨嵐の着火、雷撃、爆雷、三元共鳴、叩きつけ、社の被弾、ボスの登場、フェーズ移行、ウェーブクリア、報酬の決定、山颪の予兆。
- **BGM**:
  - ロビー・通常戦・ボス戦向けの外部ループ音源と勝利のジングル（権利が明確な OGG/WAV）を `assets/audio/` に置き、ライセンス情報を `assets/LICENSES.txt` で管理する。
  - 読み込みに失敗した場合は、組み込みのプロシージャルな和風環境音へ切り替える。
