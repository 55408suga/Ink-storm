## 2. 6 本柱

| 柱 | 定義 | 主に効く所 | 守れているかの判定 |
| :--- | :--- | :--- | :--- |
| **1. 余白** | 素紙を残し、墨と属性の動きを主役にする | 背景・地形・戦闘中の HUD | 流体の墨を除いた静的な描画物について、戦闘画面の素紙率が 60% 以上 |
| **2. 一筆の勢い** | 線には入り・送り・払いがあり、長い線は途切れずに伸びる（龍脈筆線） | 輪郭・龍脈筆線・稲妻・一筆龍 | 1 本の線の太さの比が 2.5 倍以上で、均一な太さの線がない |
| **3. 墨の五彩** | 色ではなく濃淡（焦・濃・重・淡・清）で、形と奥行きを伝える | 登場物・地形・流体 | グレースケールにしても、社・敵・弾・墨玉の区別がつく |
| **4. 色は意味** | 彩りのある色は朱・蒼・金と、幕の地色だけ。色を見れば意味がわかる | 属性・警告・強化状態 | パレットのトークン以外の色がない |
| **5. 墨還り** | 倒した妖怪は墨に還り、紙に吸われる。浄化とは紙へ還ることである | 撃破・ウェーブクリア・ボス撃破 | 撃破の演出が「消える」ではなく「還る」になっている |
| **6. 巻物と落款** | 区切りは、巻物を繰り落款を押す儀式として見せる | 報酬・リザルト・幕転換・題字 | 区切りの画面の外で巻物と落款を乱用していない |

## 4. 世界観フレーバー

- **世界**: 一巻の古い絵巻の中にある「墨界」。社は絵巻を綴じる要の祠で、その灯が消えると絵巻は墨嵐に呑まれる。
- **妖怪**: 絵師が描き損じて捨てた「反故の墨」から生まれた化身。倒すと墨に還る（墨還り＝反故を紙へ還すこと）。
- **プレイヤー**: 姿を持たない「筆」そのもの。カーソルが筆先であり、主人公の姿は描かない。
- **筆の銘**:
  - 豪筆 … 太い軸の大筆。一振りで嵐を押し返す。
  - 朱筆 … 朱墨を含んだ筆。描いた所に火が宿る。
  - 細筆 … 写経に使う細い筆。雷を呼ぶ渦を描く。
- **用語の由来**: 墨晶は還った墨が結晶したもの、墨庵は筆を休める庵、大遺物は絵巻の中に描かれた名品。
- **幕ボス**:
  - 大天狗 … 絵巻の峠を守っていた天狗が、反故の墨に染まったもの。
  - 鵺 … 夜の章に描かれた怪。雷雲を呼んで柱の間を駆ける。
  - 一筆龍 … 最終章の霊峰に、目を描かれずに封じられた龍。「画龍点睛」の故事のとおり、目を入れられた龍は飛び去る。墨嵐はその目を描き入れようとしている。
- **トーン**: 怖さより、凛とした美しさ。小型の妖怪には鳥獣戯画のような軽みを持たせる。
- **文の書き方**: フレーバーテキストは 1 行 30 字以内とし、説明より余韻を残す。

## 5. パレットのトークン

色はすべてトークンで指定する。トークンは `src/render/` 内の 1 か所（例: `palette.h`）で定義し、RGB の直書きは禁止する。hex は初期値である。

| トークン（実装名の案） | 名前 | hex | 用途 |
| :--- | :--- | :--- | :--- |
| `PAL_SUMI_SCORCH` | 焦墨 | #1A1714 | 目・最も強い輪郭・墨玉 |
| `PAL_SUMI_DARK` | 濃墨 | #2B2723 | 輪郭・流体の濃い所 |
| `PAL_SUMI_HEAVY` | 重墨 | #4A443D | 影・地形の要所・墨溜まり |
| `PAL_SUMI_LIGHT` | 淡墨 | #8C857A | 面のぼかし |
| `PAL_SUMI_CLEAR` | 清墨 | #C9C1B2 | 背景・霞・残像 |
| `PAL_GOFUN` | 胡粉 | #F7F2E6 | 紙抜き縁・白い面・目 |
| `PAL_SHU` / `PAL_SHU_HOT` | 朱 / 朱・明 | #C8442B / #F08A3C | 炎・警告の破線・落款・社の灯 |
| `PAL_AO` / `PAL_AO_HOT` | 蒼 / 蒼・明 | #2F6FB3 / #9FD3F2 | 雷（群青寄りにしてネオン調を避ける） |
| `PAL_KIN` / `PAL_KIN_HOT` | 金 / 金・明 | #C9A04A / #F1D27A | 墨昇華・偏向弾・墨玉の光・三元共鳴・砂子 |
| `PAL_BENGARA` | 弁柄 | #8E3B2C | 炎ではない赤（鳥居・大天狗の面） |
| `PAL_PAPER_ACT1` | 生成 | #EDE4D0 | 第 1 幕の地色 |
| `PAL_PAPER_ACT2` | 薄柿 | #EADCC4 | 第 2 幕の地色 |
| `PAL_PAPER_ACT3` | 冷灰 | #DAD8CF | 第 3 幕の地色 |

- **彩りのある色**は、朱・蒼・金の 3 系統、その幕の地色、弁柄だけにする。
- **朱の用途**は「炎」「警告」「落款と社の灯」の 3 つに限り、形で区別する（炎＝揺らぐ火の粉と涙滴、警告＝破線と印、落款と灯＝動かない小さな面）。
- **地色**は、どの幕でも明るさ L* 80 以上を保つ（上の値は L* 約 86〜91）。焦墨と地色のコントラスト比は 10:1 以上にする。
- **属性色は 2 層**で描く。外側に基本色、芯に明色を置き、紙の上でも濃墨の上でもコントラスト比 3:1 以上を保つ。基本色だけでは濃墨の上で約 3.4:1 にしかならないので、芯の明色を省かない。
- **不透明度**: 背景は 0.35 以下、紙抜き縁は 0.85、流体は濃度の対応曲線（§9.4）で決める。
- エリートの縁の色（金・白・朱・蒼、game-design.md §8.3）は、それぞれ `PAL_KIN`・`PAL_GOFUN`・`PAL_SHU`・`PAL_AO` を使う。
- 1 体の登場物に使う彩りのある色は 1 系統までにする（小さな目の金は除く）。

## 6. 3 幕の情景

- 背景の描画物は、画面端から 120px の帯の中だけに置く。幕の開始時に背景キャッシュ（§15）へ 1 回描く。
- 夜や嵐は、紙を暗くするのではなく、画面端の墨雲と雨の線で表す。

| 幕 | 時刻・空気 | 地色 | 端に描くもの | 地形の描き方 | 素紙率 | 描かないもの |
| :--- | :--- | :--- | :--- | :--- | :---: | :--- |
| 第一幕『開けた和紙の社』 | 夜明け。無風から風が立つ | 生成 | 下端に芒を 3〜5 本（淡墨の払い）、上端に霞のぼかし（清墨） | 地形なし | 80% | 遠景の山、建物、社の灯以外の朱 |
| 第二幕『鳥居と岩柱』 | 夕刻 | 薄柿 | 左右端に竹（縦の一筆と節の短い打ち込み）、上端に烏の群れ（小さな払いを 5〜9 個） | 鳥居は弁柄の柱と濃墨の笠木（笠木は描画のみ）。岩柱は淡墨の没骨の面に皴法 2〜3 本と濃墨の一筆 | 70% | 鮮やかな朱の鳥居（炎と紛れる） |
| 第三幕『嵐の霊峰』 | 夜の嵐 | 冷灰 | 上端に霊峰の稜線を 1 本の龍脈筆線で描き、山肌は飛白で表す。斜めの雨線（清墨、毎秒 60px でゆっくり流す）。上端 15% にうねる墨雲 | 岩柱は第二幕と同じ。霊柱は胡粉の柱に淡墨の紋を入れ、灯ると内側から属性の明色が灯る | 60% | 紙全体を暗くすること |
| エンドレス | 周回 | 各幕と同じ | 各幕の情景に加え、周回ごとに金の砂子が画面端に増える（周回 1 で 20 粒、上限 120 粒） | 各幕と同じ | 各幕と同じ | — |

- **幕転換**（`RUN_PHASE_ACT_TRANSITION`・2.0 秒）: 今の幕の絵が右から左へ巻き取られ、次の幕の絵巻が繰り広げられる。題字は中央に毛筆で書く。
- **山颪の予兆**: 風上の端の紙をはためかせ（背景キャッシュの端の帯を短冊状に分けて 1.5 秒波打たせる）、清墨の矢印を払いで 3 本描く。
- **落雷の閃き**: 紙を 2 tick だけ地色から胡粉へ明るくする。画面全体の明滅は 1 秒に 3 回までにする（§9.7）。

## 7. 配分の原則と描画層ごとの表

本書では、引き算で余白を見せる描き方を **余白型**、太い墨と飛沫で勢いを見せる描き方を **墨勢型** と呼ぶ。

- **原則**: 面積では余白型 7：墨勢型 3、時間では平常 8：見せ場 2。平常時は余白型で描き、反応・撃破・叩きつけ・ボス・幕転換の見せ場でだけ墨勢型で盛る。
- **流体が余白を戻す**: 墨の流体は 0.8 秒ほどで半分に薄れる。「描いては消える」こと自体が、余白を取り戻す演出になる。
- **大きな演出の同時上限**: 爆雷・三元共鳴・ボス撃破・幕転換などの大きな演出は、画面に同時に 2 つまでとする。1 つの長さは 0.6 秒以内にする（ボス撃破 1.5 秒・幕転換 2.0 秒は例外）。

| 描画層 | 主導 | 具体表現 |
| :--- | :--- | :--- |
| 和紙の地・背景 | 余白型 | 素紙を 60% 以上残す。背景の模様は画面端から 120px の帯の中だけに、淡墨か清墨（不透明度 0.35 以下）で描く |
| 地形（鳥居・岩柱・霊柱） | 余白型 | 輪郭を引かずに淡墨の面で描き（没骨）、要所に濃墨の一筆だけ入れる。岩は皴法を 2〜3 本 |
| 龍脈筆線 | 余白型 | 幕転換・ボス登場・風斬り・霊峰の稜線・山颪の予兆・一筆龍の体に使う。途切れない 1 本の長い線で、入り・送り・払いを持たせ、0.3〜0.6 秒かけて筆先が走るように描き出す |
| 流体の墨 | 両方 | 濃淡は淡墨のグラデーション（余白型）、縁は墨溜まりで締める（墨勢型） |
| 登場物（社・敵・ボス・弾） | 墨勢型 | 太さに強弱のある濃墨の輪郭（§10 の太さ）に紙抜き縁を重ね、筆の切れ目を 1〜2 か所入れる。彩りのある色は 1 体につき 1 系統まで |
| エフェクト | 墨勢型 | 衝撃の向きに飛ぶ筆飛沫、円相の衝撃波、墨還り |
| 戦闘中の HUD | 余白型 | 細い線、墨 1 色と朱 1 点。余白の中に小さく置く |
| 区切りの画面（報酬・リザルト・幕転換・題字） | 墨勢型 | 巻物が広がる・巻き取られる動き、落款を押す動き、毛筆の題字 |

## 8. 筆描画プリミティブ（6 種）

登場物・地形・エフェクト・区切りの UI は、次の 6 種で描く。関数名は architecture.md §9.2 と同じにする。引数は案であり、実装時に `ink_render` の内部 API として確定する。

- raylib の `DrawLine*`・`DrawCircle*`・`DrawRectangle*`・`DrawRing`・`DrawPoly*`・`DrawTriangleStrip`・`DrawSplineCatmullRom` は、1 色かつ均一な太さでしか描けない。これらは完成形の見た目には使わず、X 線表示・デバッグ・当たり判定の表示にだけ使う。
- 強弱と濃淡は、rlgl（`rlBegin(RL_TRIANGLES)` と頂点ごとの `rlColor4ub`）で作る。
- 登場物の**体**に限り、`assets/sprites/` の絵をアトラスから貼るテクスチャ付きの四角形（`rlBegin(RL_QUADS)`）を使ってよい（§10.7）。均一な太さの線ではないため、上の制限には当たらない。

```c
typedef struct {
    float w_max;          /* 最大の太さ px */
    float w_min_ratio;    /* 最小 / 最大。0.4 以下 */
    float entry;          /* 入りの長さの比（既定 0.15） */
    float exit;           /* 払いの長さの比（既定 0.25） */
    float dry;            /* かすれの量 0..1 */
    uint32_t seed;        /* 形のシード（§9.3） */
} BrushProfile;

typedef struct {
    PaletteId color;      /* §5 のトークン */
    float alpha;          /* 0..1 */
} InkTone;
```

### 8.1 `ink_stroke`（筆線）
```c
void ink_stroke(const Vector2 *pts, int n, BrushProfile prof, InkTone tone, float reveal);
```
- **用途**: 輪郭以外のすべての線（龍脈筆線、払い、稲妻、文字以外の線の装飾）。
- **振る舞い**:
  1. 制御点を Catmull-Rom 曲線で 4px 間隔に再サンプルする。
  2. 長さに沿った位置 t で太さを決める。入り（0〜`entry`）で 0 から最大へ、送りでは最大の付近をノイズで ±8% 揺らし、払い（1−`exit`〜1）で最小へ細らせる。最小の太さは 1.2px とする。
  3. 縁を、長さ方向の 1 次元ノイズ（`seed` から作る）で外側へ最大 0.6px 揺らす。
  4. `dry > 0` のとき、終わりの 30% の区間で、線の方向に沿った筋状のノイズを使って不透明度を下げ、かすれを作る。
  5. `reveal`（0..1）の割合だけ、頭から描く。描き出しのアニメーションに使う。
- **既定値**: `w_min_ratio` 0.3、`entry` 0.15、`exit` 0.25、`dry` 0。

### 8.2 `ink_wash`（ぼかしの面）
```c
void ink_wash(Vector2 center, float rx, float ry, float rot, InkTone tone, int layers, uint32_t seed);
```
- **用途**: 没骨の面、霞、墨雲、敵の体の塗り、墨吸いの体。
- **振る舞い**:
  - 12〜20 頂点の、半径を ±15% 揺らした閉じた形を `layers` 層（2〜3 層）重ねる。層ごとに中心を少しずらし、不透明度は 0.12〜0.35 にする。
  - 各層は中心の色を薄く、外周の色を濃くする（扇形の三角形で、頂点ごとに不透明度を変える）。外周を一段濃くして、たらし込みの墨溜まりにする。
- **既定値**: `layers` 2。

### 8.3 `ink_splatter`（筆飛沫）
```c
void ink_splatter(Vector2 at, Vector2 dir, float energy, InkTone tone, uint64_t *vfx_rng);
```
- **用途**: 撃破・叩きつけ・爆雷などの飛沫。粒子なので、乱数は `vfx_rng` を使う。
- **振る舞い**:
  - 主な飛沫 1 つ（`ink_wash` 1 層、半径は `energy` に比例）と、衛星の飛沫 3〜8 個を置く。衛星は `dir` を中心とした ±35° の扇の中に、`energy` に比例した距離で、遠いものほど小さく置く。
  - 飛び線を 2〜4 本描く（入りのない、払いだけの `ink_stroke`）。
  - 寿命の間に、不透明度を下げながら半径を 10% 広げ、にじんで消える。
- **形**: 衛星の飛沫は円ではなく、`dir` の向きに伸びた涙滴形にする。

### 8.4 `ink_outline`（強弱の輪郭）
```c
void ink_outline(const Vector2 *ctrl, int n, bool closed, float w_max, Vector2 shade_dir, uint32_t seed);
```
- **用途**: 登場物の輪郭。
- **振る舞い**:
  - 制御点を通る閉じた（または開いた）曲線に沿って `ink_stroke` と同じ方法で描く。
  - 太さは「w_max × (0.45 + 0.55 × max(0, 法線と `shade_dir` の内積))」とし、影の側を太く、光の側を細くする。`shade_dir` の既定は右下。
  - `seed` で決めた位置に、周長の 6〜12% の切れ目を 1〜2 か所入れる。切れ目の両端は払いで細らせる。顔や目の周りには切れ目を入れない。

### 8.5 `ink_knockout`（紙抜き縁）
```c
void ink_knockout(const Vector2 *ctrl, int n, float pad_px);
```
- **用途**: 登場物を、プレイヤーの濃い墨の上でも見えるようにする。社・敵・ボス・弾・墨玉のすべてに使う（墨吸いを含む）。
- **振る舞い**: シルエットを `pad_px`（既定 3px）外側へ広げた形を、その幕の地色に胡粉を 50% 混ぜた色・不透明度 0.85 で塗る。輪郭より先に描く。

### 8.6 `seal_stamp`（落款）
```c
void seal_stamp(TextId glyph, Vector2 at, float size, SealStyle style, float t);
```
- **用途**: 決定と区切りの印（§12.3）。
- **振る舞い**:
  - 角印（または丸印）の縁を ±1.5px 揺らし、朱で不透明度 0.92 に塗る。面の中に 2〜3 か所、小さなかすれの穴を開ける。
  - `style` が白文なら文字を白抜きにし、朱文なら朱の文字を胡粉の面に置く。
  - ±4° 傾ける。
  - `t`（0..1）で押印を動かす。最初の 0.08 秒で 1.3 倍から 1.0 倍へ縮め、その後 0.3 秒かけて朱を 3% にじませる。
- **フォント欠損時**: 文字を描かず、印の形だけを押す。

## 9. 描画規約（数値）

### 9.1 線
- 1 本の線の中で、太さの最大と最小の比を 2.5 倍以上にする。
- すべての線に入りと払いを付ける。最小の太さは 1.2px。
- 輪郭には、周長の 6〜12% の切れ目を 1〜2 か所入れる。
- 200px を超える長い線は、途切れない 1 本で描く（龍脈筆線）。

### 9.2 形と面
- シルエットは制御点で作り、左右非対称にする（10% 以上ずらす）。正円・正多角形・矩形を、そのまま体にしない。
- 登場物 1 体に、墨の 5 段階のうち 3 段階以上を使う（例: 輪郭と目＝焦墨か濃墨、体の面＝淡墨、影と残像＝清墨）。
- 面は 2 層以上の `ink_wash` で塗り、面積の 10〜25% を飛白として塗り残す。

### 9.3 再現性
- 形のシードは、`EntityId` の `index`・`gen` と部位の番号から作る。`vfx_rng` は粒子（飛沫・火の粉・稲妻の枝）にだけ使う。
- 線のふるえ（ボイル）は、6 tick ごとにシードを切り替え、振れ幅を 0.8px 以下にする。tick から決めるので、`--snap` の比較で結果が再現する。
- 背景と地形は、幕ごとに固定したシードで描く。
- HUD・UI はボイルさせない。

### 9.4 流体の墨
流体格子（160×90）は GPU の水墨シェーダで 1280×720 に描く（シェーダを使えないときは CPU の表引きで同じ曲線を再現する）。濃度 d を次の曲線でトーンへ対応させる。濃度をそのまま不透明度にすると、画面全体が灰色の霧になるので使わない。段差を作らず、各区間は滑らかにつなぐ。

| 濃度 d | トーン | 不透明度 |
| :--- | :--- | :--- |
| 0.05 未満 | 紙のまま | 0 |
| 0.05〜0.25 | 清墨 → 淡墨 | 0.15 → 0.45（smoothstep） |
| 0.25〜0.8 | 淡墨 → 濃墨 | 0.45 → 0.85 |
| 0.8 以上 | 焦墨 | 0.92 |

- **墨溜まり**: 墨の縁のすぐ内側を、濃度の勾配に比例して連続的に濃くする（重墨寄り）。しきい値で切り替える二値の段差は作らない。
- **にじみと紙**: 格子は B スプライン双三次補間で滑らかに拡大し、8px の升目を見せない。和紙テクスチャの繊維で標本位置をわずかにずらしてにじみ縁を有機的にし、紙のくぼみに墨が溜まる粒状感を足す。
- **炎と雷**: 外側を基本色、強い所を明色、さらに強い芯を白熱・電光にする（§5 の 2 層の規則）。炎と雷が重なった所は、どちらかで塗りつぶさず金色の光へ混ぜる。乗算済みアルファで合成し、透明域が黒くにじまないようにする。墨と重なった所は、墨のトーンの上に属性色を重ねる。
- 岩柱・霊柱などの `solid` セルには墨を描かない。

### 9.5 描画順
1. 和紙の地と山水背景（不透明な背景キャッシュ。画面揺れ用に四辺 16px の余白を持つ）
2. 流体
3. 地形（墨が回り込む岩柱・鳥居・霊柱は墨の上に立つ）
4. 墨玉・敵弾
5. 登場物（紙抜き縁 → 面 → 輪郭 → 目）。絵の登場物は次の段で描く。
   - A0（通常合成）: 全員の紙抜き縁を先に描く（絵のアルファから作った縁、一筆龍の胴・狐と鵺の尾の筆線の縁）。隣の縁が別の体に食い込まない。
   - A（通常合成、1 体ずつ）: エリートの縁 → 下に敷く手続きの部品 → 絵 → 上に重ねる部品 → 状態表示。龍玉は一筆龍の胴の後に描く。
   - B（乗算合成）: 灯籠の灯り、社の窓の朱。紙だけを染め、骨や墨の線は濁らせない。
   - C（通常合成）: 熱い芯（社の灯火、灯籠の口）。B の後に描き、暗くしない。
6. エフェクト
7. ポストシェーダ
8. HUD・UI（必ずポストシェーダの後に描き、文字をにじませない）

背景キャッシュの山水は、外周（上端の連山・左右端の岩・竹・松・滝）に重みを置き、中央の戦場は淡い霧と高い明度のまま残す。ロビー、第 1 幕（暁の社・連山と松と滝霧）、第 2 幕（暮れの竹林渓谷）、第 3 幕（嵐の霊峰・岩壁と墨雲）を描き分け、エンドレスでは砂子（金箔片）を本来の金色で散らす。

### 9.6 文字
- 毛筆体は 40px 以上の題字・落款・大きな反応名だけに使う。
- 本文と数値は明朝体で 18px 以上、コールアウトは 28px 以上にする。数字は幅をそろえ、値が変わっても揺れないようにする。
- 文字の下には和紙の帯か、胡粉の紙抜きを敷く。

### 9.7 明滅・揺れ・合成
- 画面全体の明滅は 1 秒に 3 回までにする（光に敏感な人への配慮）。
- 画面揺れは、設定の画面揺れ（100% / 50% / 0%）に従う。
- **合成モード**:
  - 墨（無彩色）の面と線は乗算合成（`BLEND_MULTIPLIED`）を基本にし、重ねるほど濃くなるようにする。流体の GPU 経路は墨と属性色を 1 パスの乗算済みアルファで合成する（墨は紙の繊維を写した色で覆い、属性色は一部を加算的に光らせる）。
  - 紙抜き縁、胡粉、属性色は通常のアルファ合成にする。
  - 加算合成は、雷の芯（中心 1〜2px）と金・明の小さな光だけに使う。
  - 合成モードの切り替えはバッチを分けるので、層ごとに同じ合成モードの描画をまとめる。

## 10. 登場物の意匠

### 10.1 輪郭の太さ（`w_max`）

| 区分 | 対象 | `w_max` |
| :--- | :--- | :---: |
| 小型 | 弓妖・提灯妖・鎌鼬・狐符・敵弾 | 3px |
| 中型 | 社・唐傘妖 | 3.5px |
| 重量級 | 石鬼 | 6px |
| ボス | 大天狗・鵺・一筆龍 | 5〜8px |

### 10.2 社
- 反った屋根の一筆（濃墨の `ink_stroke`）、胡粉の壁、注連縄の細線。
- 朱の灯を中心に置き、HP に応じて灯の大きさと揺らぎを変える。被弾すると灯が揺らぎ、紙にひびの線（重墨の細い折れ線）が入る。
- 提灯妖と見分けられるよう、灯は屋根の下に置き、丸い提灯の形にはしない。

### 10.3 通常敵

| 敵 | 古典の手がかり | シルエットの要点 | 墨と色 | 動き |
| :--- | :--- | :--- | :--- | :--- |
| 弓妖 | 白描の人物 | 痩せた影の射手。頭巾はにじみ、弓は長い 1 本の払い線 | 濃墨の輪郭、淡墨の体 | 射る前に弓を引き絞り、払い線がしなる |
| 提灯妖・炎 / 雷 | 妖怪画集の器物の怪 | 破れた提灯。骨は強弱のある曲線、胴は胡粉、破れ目から舌が出る | 中の灯だけが朱（炎）か蒼（雷） | 灯が呼吸するように明滅する |
| 唐傘妖 | 妖怪画集の器物の怪 | 一本足の一つ目。傘の骨は放射状の強弱線 | 濃墨の骨と淡墨の布 | 跳ねる。吹き飛び中は回転し、布がはためく |
| 鎌鼬 | 鳥獣戯画の軽み | 鎌形の払い線 3 本で体を作る | 濃墨の払いと淡墨の残像 | 通った跡に淡墨の残像を 0.3 秒引く |
| 石鬼 | 雪舟の皴法 | ずんぐりした岩の鬼。皴法の岩肌に濃墨の割れ線 | 輪郭は最も太い 6px。重墨の面 | 一歩ごとに足元へ小さな墨が撥ねる |
| 墨吸い | 潑墨・たらし込み | 墨のにじみそのもの。輪郭を描かない唯一の例外 | 体は `ink_wash`、目は胡粉。紙抜き縁は付ける | 吸った墨の量に応じて、にじみの径が広がる |
| 狐符 | 白描と短冊 | 胡粉の狐面と、筆の払いの尾 | 濃墨の輪郭。符は胡粉の短冊 | 尾が筆のように揺れる |

### 10.4 エリート
- 体を 1.2 倍にし、紙抜き縁の外側に、変異の色の縁（金・胡粉・朱・蒼）を 2px 足す。
- 変異の縁は `ink_stroke` の破線ではなく、途切れのない細い線にする（警告の朱の破線と区別するため）。

### 10.5 幕ボス

**大天狗**
- 弁柄の面（炎の朱と分ける）を濃墨の輪郭で締める。
- 翼は、飛白の多い大きな払いを 5〜7 本重ねて描く。羽団扇は放射状の払いにする。
- 紅の敵風は、薄く朱を含ませた清墨の流線で描く。

**鵺**
- 猿の面（胡粉）、狸の胴（淡墨の没骨）、虎の脚（濃墨の縞の打ち込み）、蛇の尾（細い払い）。
- 黒雲（淡墨のぼかし）が体を包み、蒼の稲妻をまとう。
- ダッシュの跡に、清墨の龍脈筆線を 0.5 秒残す。
- 止まっている間は輪郭を 1.3 倍に太らせ、身を沈めた姿勢にする。叩きつけが効く間であることを、形で伝える。

**一筆龍（霊峰の龍脈）**
- **体**: 頭から尾までを 1 本の `ink_stroke` で描く。`w_max` は 26px で、頭の側を太く入れ、尾に向かって払う。尾の 30% はかすれさせる（`dry` 0.6）。制御点には頭の軌跡の履歴（24 点）を使う。
- **鱗**: 胴に沿って、皴法のような短い打ち込みを 40〜60 本置く（淡墨〜重墨）。
- **頭**: 角 2 本と髭 2 本は細い払い、口は濃墨の一筆。目は、点睛の前は胡粉の空白（輪郭だけの円）にしておく。
- **龍玉**: 上の尖った宝珠形に、火焔の縁を付ける。
  - 炎玉（頭）: 朱。芯は朱・明。
  - 雷玉（胴）: 蒼。芯は蒼・明。
  - 風玉（尾）: 胡粉に淡墨の渦文（風は色を持たない）。
  - 攻撃の 0.6 秒前に、その属性の明色で内側から光らせる。
- **龍玉が壊れたとき**: その位置の筆線のかすれを強め（`dry` を上げる）、線が途切れがちになるようにする。
- **点睛**: 1.5 秒、画面の動きを抑え、大きな筆が目に朱の点を入れる。その後、龍の線を一段濃い墨へ変え、全身の輪郭を締める。
- **撃破**: 筆線が頭から尾へ向かってほどけ、霊峰の稜線へ墨として流れ還る。
- **簡易版（P1）**: 胴は描画だけで、`ink_render` が頭の位置の履歴を持つ。龍玉は頭の 1 つだけで、色が炎 → 雷 → 風と変わる。

### 10.6 敵弾・偏向弾・墨玉

| 対象 | 形 |
| :--- | :--- |
| 矢 | 細い払い線。矢羽は短い払いを 3 本 |
| 火球 | 朱の涙滴形。芯は朱・明。尾に火の粉 |
| 雷球 | 蒼の宝珠形。芯は蒼・明。周りに短い稲妻を 2 本 |
| 鎌風 | 三日月形の払い（淡墨に胡粉の縁） |
| 追尾符 | 胡粉の短冊に墨の文字線。燃えるときは端から朱に焦げる |
| 跳弾雷球 | 雷球と同じ形。反射するたびに、小さな欠けた円相を残す |
| 偏向弾 | 金の縁を付け、尾を龍脈筆線のように伸ばす。炎上弾は尾が朱、雷撃弾は尾が蒼 |
| 墨玉 | 焦墨の玉に、金・明のハイライトを 1 点。紙抜き縁を付ける |

### 10.7 絵の登場物（スプライト）

社・通常敵 8 種・幕ボス 3 体・龍玉 3 種の体を、同じ絵師が一度に描いた絵巻の 1 枚として揃える。

- **枚数とキャンバス**: 中核 20 枚（任意の差分 `ofuda_fox_cast.png` を除く）。通常敵・社・龍玉は 256²、ボスは 512²。表示の大きさは `2r / k`（k は当たり判定の直径 / キャンバス幅。社は 128px 固定）で、常に縮小して表示する。
- **構図**: 斜め上から見下ろす 3/4 の視点で、右向きだけを描く（向きはエンジンが反転・回転する）。光は左上から。影・地面・背景は描かない。外周 8% は透明の余白にする。
- **色**: 墨の 5 段と胡粉が基本で、胡粉より明るい色は使わない。差し色はキャラクターごとに 1 色だけで、基本のトークン（朱・蒼・金・弁柄）だけを塗る。`*_HOT` の色は描き込まず、手続き描画が光らせる。
- **輪郭**: 胡粉の面はすべて途切れない墨の輪郭で囲み、外形の輪郭も墨にする。輪郭の切れ目は淡墨のかすれで残し、紙の白で切らない。
- **紙抜き縁**: 読み込み時に絵のアルファを半分の解像度へ縮め、円盤で膨らませてぼかした縁を作る。絵と同じ変換で動かし、`ink_knockout` と同じ色（幕の和紙と胡粉の中間、α 0.85）で塗る。
- **動き**: 呼吸の伸縮、6 tick ごとのボイル（0.8px 以内）、±0.25 の履歴付きの左右反転と 6 tick の紙の裏返し、被弾時の墨の持ち上がり（白い明滅を使わない）、墨還りでの沈み込み。時間はすべて `ticks` から求め、`--snap` を再現できるようにする。
- **一筆龍**: 胴は弧長で 64 点に置き直した一筆の筆線で、首の差し込み口と生きた龍玉の位置ではうねりを止め、玉の当たり判定から胴を外さない。頭の絵は胴の首に差し込み、髭・点睛・角の金線は手続き描画で重ねる。
- **フォールバック**: 必須の絵が欠ける・読めない・寸法が違うときは、そのキャラクター全体を手続き描画で描く。状態差分だけが欠けたときは基本の絵を使い、状態の手がかりは手続きの部品で示す。龍玉は 3 種がそろったときだけ絵にする。

## 12. UI（巻物・落款・文字）

### 12.1 戦闘中の HUD（余白型）
表示する項目は game-design.md §11.5 に従う。見た目は次のとおりにする。
- **墨リング**: 太さ 3px の円弧の `ink_stroke`。両端を細らせる。かすれの目盛り（墨 20 の位置）は短い打ち込み、墨昇華の間は金にする。
- **準備ピップ**: 小さな墨の点。使えるときは濃墨、CD 中は清墨で、塗りが満ちていく。
- **社 HP**: 朱・明の小さな炎形の灯火の印を、HP の数だけ並べる。
- **上端の和紙帯**: 地色を不透明度 0.8 で敷き、下の縁に淡墨のかすれ線を引く。
- HUD の線は、ボイルさせない。

### 12.2 区切りの画面（墨勢型）
- **報酬選択**:
  - 3 枚の札を、縦長の胡粉の短冊として描く。上部に軸の色の小さな印を押す（紅蓮＝朱、雷霆＝蒼、烈風＝重墨の渦文、墨道＝金、共通＝胡粉に墨）。
  - 選ぶと、その札に落款を押す。
  - リロールすると、札が墨に還り、新しい札が筆で描き出される（0.4 秒）。
  - 「社を修繕」は、社の形をした小さな札にする。
- **大遺物の選択**: 巻物の上に、3 つの名品を淡墨で描き、題簽に名前を書く。
- **リザルト**: 絵巻を右から左へ繰り広げ、項目を筆で書き出す。墨晶の内訳は、帳簿のような縦の罫線で並べる。
- **墨庵**: 庵の掛け軸に商品を並べる。
- **タイトル**: 題字「墨嵐」を毛筆で大書きし、朱の落款を押す。背景では流体が動く。
- **ポーズ**: 画面に薄い和紙を 1 枚掛け、その上にメニューを置く。

### 12.3 落款の規約
- 落款を押すのは、決定と区切りだけにする（選択の決定、ウェーブクリア、幕クリア、三元共鳴、タイトル）。
- 1 画面に同時に押す落款は 2 つまで。
- 決定には白文、装飾には朱文を使う。
- 印の文字は文字列表の ID で指定する（例: 祓・討・三元・墨嵐）。

### 12.4 文字
- §9.6 に従う。題字は縦書きにしてもよいが、本文と数値は横書きにする。
- フォントが欠けた場合は、文字列表の英語（ASCII）で描き、落款は印の形だけを押す。

## 13. NG 集

| NG | 理由 | 代わりにどうするか |
| :--- | :--- | :--- |
| 同じ太さの線で引いた輪郭、正円の目玉 | 平らな図形に見える | `ink_outline` の強弱と切れ目 |
| 正円の胴に正方形の帽子を載せるような図形の合成 | 記号に見え、筆で描いた感じがしない | 制御点で作るシルエット |
| RGB を直書きした単色のベタ塗り | パレットが崩れ、平らに見える | トークン色の `ink_wash` 2 層と塗り残し |
| 円を重ねた発光、加算合成の多用 | ネオン調になる | にじみのぼかしと紙抜き。加算合成は雷の芯だけ |
| 原色に近い高彩度の色 | 和紙の上で浮く | §5 の落ち着いたトークン色 |
| 背景を全面に描き込む | 余白がなくなり、流体の墨が読めない | 画面端 120px の帯の中だけに描く |
| すべての登場物を同じ太さ・同じ黒で描く | 主従がなくなる | §10.1 の太さと、墨の段階で差をつける |
| 円の点を集めたパーティクル | 筆の飛沫に見えない | 向きのある涙滴と飛び線（`ink_splatter`） |
| 完全な円の衝撃波リング、対称な放射 | 機械的に見える | 欠けのある円相と、向きを持った払い |
| 黒い墨の上に、縁のない黒い敵を置く | プレイヤーの墨に敵が沈む | `ink_knockout` の紙抜き縁 |
| 毎フレーム乱数で形を震わせる | ちらつき、`--snap` の比較もできない | 固定シードと 6 tick ごとのボイル |
| 紙を暗くして夜を表す | 墨が読めなくなる | 地色は明るいまま、端の墨雲と雨の線 |
| ポストシェーダの前に UI を描く、小さな毛筆体の文字 | 文字がにじんで読めない | ポストシェーダの後に描く、明朝体 18px 以上 |
| 鮮やかな朱の鳥居、朱の大きな面 | 炎や警告の朱と紛れる | 弁柄と墨で描く |
| 1 秒に 3 回を超える画面全体の明滅 | 光に敏感な人に負担がかかる | 明滅は 1 秒に 3 回まで、明るさの変化は控えめに |
| 特定の既存作品を連想させる固有の意匠（例: 赤い隈取りの紋を持つ白い獣の主人公、時間が止まって画面全体が紙の色に変わる描画モード、花が一斉に咲いて色が戻る浄化） | 模倣に見え、INKSTORM 独自の見た目にならない | 筆＝カーソル、墨還り、円相、落款など本書のモチーフ |
| 見た目の味をポストシェーダだけに頼る | `--no-post` やシェーダ失敗時に平らになる | 形・濃淡・墨溜まりは CPU 側で作る（§14.1） |
| 絵の中の純白のハイライトや目 | 切り抜きで穴が開き、樹脂のように見える | 胡粉を焦墨の縁で囲む |
| 胡粉の面を囲む輪郭が開いている | 切り抜きで顔や面が消える | 輪郭の切れ目は淡墨のかすれにする（§10.7） |
| 炎・灯り・稲妻・`*_HOT` の発光を絵に描き込む | 呼吸も予兆もできず、手続きの光と二重になる | 取り付け位置を空けておき、エンジンが描く |
| 絵に影・地面・背景を描く | 流体の墨とぶつかり、切り抜けない | 地面のにじみはエンジンが足す |
| 左向き・正面向きの差分を描く | 反転の規則が崩れる | 右向きだけを描く |
| エアブラシ調のグラデーション、3D 調の陰影、アニメ調の塗り | 絵巻の筆致から外れる | 重ねたにじみと塗り残し、古典の線 |
| 絵に読める文字・署名・落款を入れる | 意味が紛れ、朱の意味が崩れる | 抽象的な筆の点だけにする |

## 14. セルフチェックと `--no-post` の契約

### 14.1 `--no-post` の契約
墨らしさの 8 割は CPU 側（形・濃淡の対応曲線・墨溜まり・筆描画プリミティブ）で作り、ポストシェーダは質感の 2 割にとどめる。

| `--no-post`・シェーダ失敗時に失ってよいもの | 失ってはならないもの |
| :--- | :--- |
| 紙の繊維、にじみ縁の細かな階調、ビネット | 形、濃淡の順位、紙の地、紙抜き縁、文字、予兆の表示 |

- 紙の地は、起動時にトーラス上の値ノイズ（継ぎ目のない 512×512）と、反りの小さい楮の繊維、温かみのある濃淡ムラで 1 回だけテクスチャを作り、ポストシェーダの有無に関係なく敷く。
- 墨溜まりは、§9.4 の濃度の対応曲線（表引き）で CPU 側に作る。

### 14.2 見本帳シーン
次のものを 1 画面に並べた固定シーンを CLI オプション `--showcase` で起動できるように用意し、固定シードで確認・撮影する（CLI 契約と障害注入は [qa-and-testing.md](qa-and-testing.md) §4・§5.1 を参照）。
- 全登場物（待機・攻撃の構え・被弾の 3 状態）
- 全敵弾、偏向弾、炎上弾、雷撃弾、墨玉
- 6 種の筆描画プリミティブの見本
- 4 つの属性反応と墨還りの途中の 1 コマ
- パレットのトークンの色見本
- HUD と、報酬・リザルトの UI 部品

見本帳は、qa-and-testing.md §5.1 の描画経路（通常、`--no-post`、`INKSTORM_DEBUG_FAULTS=shader`、`INKSTORM_DEBUG_FAULTS=font`、併用 `shader,font`、絵を使わない `INKSTORM_DEBUG_FAULTS=sprites`）すべてで確認・撮影する。あわせて、`assets/` のない場所へ実行ファイルだけを複製して起動する確認も行う。

### 14.3 崩し試験
見本帳と戦闘中のスナップについて、次の 4 つを確かめる。
1. **グレースケール**: 色を抜いても、社・敵・弾・墨玉の区別がつくか（柱 3）。
2. **5px ぼかし**: ぼかしても、登場物のシルエットが残るか。
3. **25% に縮小**: 縮めても、主役（社・ボス・予兆）がわかるか。
4. **墨が満ちた状態**: 画面の 6 割を濃墨で覆った状態でも、敵が見えるか（紙抜き縁が効いているか）。

絵の登場物では、あわせて次を確かめる。グレースケールでは明度の階級（§10.7 の絵ごとの平均明度）で隣り合うキャラクターが分かれること、25% の縮小で各キャラクターの特徴の形が残ること、墨が満ちた状態で絵の墨の輪郭が紙抜き縁の内側に収まること。

### 14.4 描画の作業を終える前のチェックリスト
- [ ] 完成形の見た目に、§8 の冒頭で挙げた raylib の均一な描画関数を使っていない。`grep -nE "Draw(Line|Circle|Rectangle|Ring|Poly|TriangleStrip|Spline)" src/render` の結果が、X 線表示・デバッグ・プリミティブの内部だけである。
- [ ] 色の指定がトークンだけである。`grep -nE "\(Color\)\{" src/render` の結果が、パレットの定義だけである。
- [ ] 見本帳を §14.2 の描画経路すべてで撮り、§14.3 の崩し試験を通した。
- [ ] 絵を差し替えたときは、`INKSTORM_DEBUG_FAULTS=sprites` と絵のない状態でも撮り、キャラクター単位で手続き描画へ戻ることを確かめた。
- [ ] `F1` の表示で、描画時間・頂点数・合成モードの切り替え回数が §15 の予算に収まっている。
- [ ] §13 の NG に当てはまるものがない。

## 15. 描画性能予算

- **全体**: `render_draw` の CPU 描画コマンド発行時間を **4.0 ms/frame 未満**にする（Release・1280×720、[architecture.md](architecture.md) §9.2・[qa-and-testing.md](qa-and-testing.md) §3）。
- **内訳の目安**:

| 項目 | 目安 |
| :--- | :--- |
| 流体テクスチャの合成と `UpdateTexture` | 0.6 ms 以下 |
| 背景と地形（キャッシュを 1 枚貼るだけ） | 0.1 ms 以下 |
| 登場物 | 1.5 ms 以下 |
| エフェクト | 1.0 ms 以下 |
| HUD・UI | 0.5 ms 以下 |

- **上限**: 筆描画プリミティブの頂点数は 1 フレーム 60,000 以下、合成モードの切り替えは 1 フレーム 12 回以下。
- **絵の登場物**: 1 体あたり紙抜き縁と絵の四角形 2 枚（8 頂点）に、手続きの部品（弓・尾など）を足す。絵は 2048² のアトラス 1 枚（ミップを含め約 21 MiB）にまとめ、読み込みは起動時の 1 回で 150 ms 以内を目安にする。乗算の段（§9.5 の B）は合成モードの切り替えを 2 回増やし、描くものがないフレームでは切り替えない。
- **キャッシュ**:
  - 背景と地形は、幕の開始時に `RenderTexture` へ描き、毎フレームは 1 枚を貼るだけにする。幕転換の巻物の動きには、今の幕と次の幕の 2 枚を使う。
  - 登場物の形（制御点から再サンプルした頂点）は、ボイルの周期（6 tick）ごとにだけ計算し直す。
  - 文字の寸法は、文字列 ID ごとに測った結果をキャッシュする。
- **予算を超えたときに落とす順番**（形・濃淡の順位・紙抜き縁は落とさない）:
  1. ボイルの周期を 6 tick から 12 tick へ伸ばす（その前に、鎌鼬の残像と墨吸いの墨晶を落とす。絵と紙抜き縁は落とさない）。
  2. 飛沫の衛星の数を半分にする。
  3. 鱗などの細部の打ち込みを半分にする。
  4. 背景キャッシュの解像度を 1/2 にする。
- **`F1` の表示**: 描画時間（ms）、筆描画プリミティブの頂点数、合成モードの切り替え回数を表示する。
