# 流体の実装と検証

- 速度場、圧力投影、渦度、境界条件、汎用のスカラー場を担当するのは `src/fluid/`。
  墨と炎の着火、墨と雷の伝導、敵やダメージの扱いは `src/game/elements/` に置く。
- 固定 60 Hz の刻み、格子の境界と添字、サンプリングと注入の入力範囲を明示する。
  クランプは境界や値域の契約に従い、テストでは NaN・Inf や発散を検出する。
- 静止場、中心への注入、端や四隅での注入、強い入力を連続した場合を試す。
  移流で範囲外を読まないこと、境界条件を保つこと、投影後の発散が低下することを数値で確認する。

## 決定性の確認

1. 初期格子、シード、各ティックの注入位置と量を固定する。
2. 同じビルドで初期化から複数回走らせ、同じティック数における速度・スカラー場のハッシュを比較する。
3. ハッシュはフィールドを固定順に追加する。構造体のパディングや計測時間は対象外とする。
4. 差があれば最初に差が出たティックとフィールドを特定する。

## 性能の確認

- Release の 160×90 格子で、代表的な注入と境界を含む同じ入力列を繰り返す。
- ウォームアップ後にソルバのステップ時間を測る。描画を計測から外し、予算の 2.0 ms 未満か確認する。
- 測定環境、ステップ数、計測した分位点、変更前後の値を記録する。
- 数値テストは ASan/UBSan で実行し、性能の判定には Release の値を使う。
